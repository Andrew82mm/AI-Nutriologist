# AI-Nutriologist

**Персональный ИИ-агент-нутрициолог.** Он знает, какие продукты есть у вас дома, что вы уже съели, считает БЖУ и калории и помогает планировать питание и покупки — при минимуме ручного ввода.

## Идея

Обычные трекеры питания заставляют вручную вносить каждый продукт и каждый приём пищи — это скучно, и почти все бросают. AI-Nutriologist убирает эту рутину: он подтягивает данные из ваших электронных чеков и понимает обычные фразы вроде «съел тарелку гречки с котлетой». Вам остаётся только жить, а учёт ведётся сам.

## Как это работает

```
Чеки из почты ─┐
Ручные правки ─┤→  Холодильник (что есть дома)
                │
«Съел X» ───────┤→  Дневник питания  →  БЖУ и калории  →  Отчёты
                │
Ваши цели ──────┴→  План питания · список покупок · рецепты из того, что есть
```

1. **Знает, что у вас дома.** Вы пересылаете электронные чеки (письма от ОФД) на выделенный почтовый ящик — агент сам их читает, распознаёт список покупок и пополняет «холодильник». Можно и вручную поправить: что-то купили без чека, что-то выбросили или закончилось.
2. **Знает, что вы съели.** Пишете в чат в свободной форме — «съел два яйца и кофе», — агент разбирает фразу и заносит в дневник.
3. **Считает БЖУ и калории.** Сопоставляет продукты со справочниками нутриентов; если данных нет — оценивает и честно помечает это как оценку.
4. **Помогает планировать.** Держит в уме ваши цели по калориям и БЖУ, подсказывает, что приготовить из имеющихся продуктов, и составляет список покупок с учётом того, что уже есть дома.

## Преимущества

- **Минимум ручной работы.** Чеки читаются автоматически, приёмы пищи вводятся обычным текстом — не нужно искать продукт в каталоге и взвешивать каждую порцию.
- **Полная картина.** Учёт связывает три вещи, которые обычно живут порознь: что куплено, что съедено и что осталось дома.
- **Приватность.** Все данные хранятся локально, на вашем устройстве, а не в чужом облаке.
- **Честные цифры.** Там, где есть точные данные из справочника, используются они; оценки от ИИ всегда помечены — вы видите, чему доверять.
- **Не привязан к одному ИИ-провайдеру.** Можно подключить облачную модель или запустить локальную — выбор за вами, меняется одной настройкой.
- **Работает даже без ИИ.** Чеки привычных сетей распознаются обычными правилами — бесплатно и стабильно; ИИ подключается только для незнакомых форматов.

## Возможности приложения

Веб-интерфейс состоит из нескольких экранов:

- **Холодильник** — что и в каком количестве есть дома прямо сейчас.
- **Дневник** — приёмы пищи за день с подсчётом БЖУ и калорий относительно цели.
- **Статистика** — как питание выглядит в динамике.
- **План** — идеи меню и список покупок под ваши цели.
- **Профиль** — цели, ограничения и параметры тела.

## Как запустить

Нужен Python 3.12+ и Node.js (для веб-интерфейса).

```bash
# 1. Бэкенд
python3 -m venv .venv
.venv/bin/pip install -e ".[api]"
.venv/bin/python -m nutriologist.api        # http://127.0.0.1:8000

# 2. Фронтенд (в отдельном терминале)
cd web/app
npm install
npm run dev                                  # http://localhost:5173
```

Чтобы включить разбор незнакомых чеков и оценку БЖУ через ИИ, скопируйте `.env.example` в `.env` и укажите провайдера и ключ. Без этого приложение тоже работает — просто без ИИ-функций.
